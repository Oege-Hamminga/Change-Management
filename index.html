One-click from Bugtracker

Creates a browser bookmark that, when clicked on the bugtracker page, sends the table data straight here.

Setup — add the bookmark (once)

  1. Click Copy Bookmarklet URL below
  2. Open your browser's bookmark manager:
    Chrome / Edge: Ctrl+Shift+O → right-click a folder → "Add new bookmark"
    Firefox: Ctrl+Shift+B → right-click → "New Bookmark"
  3. Set the name to Import to Tracker, paste the URL in the address field, save

Every time you want to refresh data

  1. Open http://srvr-bugtracker/view_all_bug_page.php
  2. Click the Import to Tracker bookmark
  3. A confirmation box tells you the data was copied — click OK to open the tracker
  4. Go to Import Data tab → click Read from Clipboard → click Import

The bookmarklet also captures ticket links so IDs in the Tracker become clickable links back to the bugtracker.

Paste or Read from Clipboard

Paste manually (Ctrl+V) or click the button to read the clipboard automatically.
